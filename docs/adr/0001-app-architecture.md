# Expo clients and a TypeScript API

v1 needs iOS, Android, and web, and a server that holds the Resident gate, matching, chat, and personal data. A browser-only SPA cannot keep those secrets or enforce the gate. Expo (React Native) is the client the product already chose; a TypeScript API is the server. The sanctioned stack id is C (closest fit). Entra is the wrong identity model for a consumer dating Account.

Status: proposed (needs confirmation that Expo-plus-TypeScript-API under id C is accepted)
