# Azure EU, web on Static Web App, API on Container Apps

Personal data stays in the EU (NFR-1). Azure is the provider the workflow can actually emit. The web client is static (Expo web). The API is a container so it can run in an EU region with a rehearsed revision rollback. App Service would also work; Container Apps is the better fit for a single API process and push-worker later.

Status: proposed

NFR-1, NFR-7.
